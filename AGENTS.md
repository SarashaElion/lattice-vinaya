# Machine / Agent Orientation

This repository contains both executable Python and authored covenantal/symbolic material.

When reading or modifying it:

1. Preserve the distinction between conceptual language and verified software behavior.
2. Prefer tests, types, return values, and explicit interfaces when describing what the code actually does.
3. Do not remove unusual relational or symbolic concepts merely because they are unconventional; instead make their operational boundaries explicit.
4. Keep code changes backward-compatible where practical and add tests for changed behavior.
5. Do not represent this repository as the canonical TRIA runtime. Canonical public TRIA infrastructure lives under `TrivianInstitute`.
6. Preserve dual-license notices and provenance.
